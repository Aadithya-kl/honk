> honk

A fast, keyboard-driven IRC client for your terminal.

curl -fsSL https://agustingianni.github.io/honk/install.sh | sh

macOS and Linux, Apple Silicon and Intel. One file, no runtime to install. The script checks the download's checksum and puts honk in ~/.local/bin, without sudo. Read the script or download a binary yourself.

Start

Connect to a server and join a channel:

honk --server irc.libera.chat --nick your_nick --channel '#libera'

To connect to several servers when honk starts, write a config file.

What you get

  • An omnibox: press Ctrl+K and type to jump to any channel, DM or person, or to run a command.
  • Several servers at once, with TLS by default and SASL login.
  • Older messages load from the server, on networks that support chat history.
  • Messages you send from your phone or another client show up here too.
  • mIRC colors, a color for each nick, a marker at your first unread line, and highlighted mentions.

Keys

Ctrl+KOpen the omnibox
Alt+Up / DownPrevious or next channel or DM
TabComplete a nick or a command
Ctrl+BShow or hide the channel list
Alt+UShow or hide the user list
/helpList every command
